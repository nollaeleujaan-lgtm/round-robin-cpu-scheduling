# Round Robin CPU Scheduling

## Deskripsi Proyek

Proyek ini merupakan implementasi struktur data Singly Linked List pada simulasi penjadwalan CPU menggunakan algoritma Round Robin berbasis Pemrograman Berorientasi Objek (PBO) dengan bahasa pemrograman Python.

Proyek ini dibuat untuk memahami penerapan struktur data dinamis dalam pengelolaan proses CPU serta mekanisme pembagian waktu eksekusi menggunakan algoritma Round Robin.

## Tujuan Proyek

1. Mengimplementasikan struktur data Singly Linked List.
2. Menerapkan konsep Pemrograman Berorientasi Objek (PBO).
3. Mengimplementasikan algoritma Round Robin.
4. Melakukan pengelolaan data proses CPU.
5. Membuat simulasi penjadwalan proses CPU menggunakan Python.
